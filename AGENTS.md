# Repository presentation and demos

Follow the shared format in aaitor/oss-repo-template. The approved demo specifications are in `examples/demo-spec.json`. Keep the README focused on the actual skill, with detailed setup and usage in `docs/`.

For demo updates, read `examples/README.md`. Record real skill installation and Claude Code usage on a black 1280 × 640 canvas. Omit waiting time while preserving actual commands and output. Stop at preview and the approval prompt unless the exact text and target account are explicitly approved. Never use `--live` in tests or CI. Keep credentials out of instructions, recordings, and commits.
