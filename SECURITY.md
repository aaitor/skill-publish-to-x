# Security policy

Report vulnerabilities privately to **aaitor@gmail.com** with the affected commit/version, impact, and a minimal reproduction using synthetic data. Do not include keys, tokens, private posts, or live account data. Use private reporting in the Security tab if available.

Do not open public issues for vulnerabilities or test against another account. Fixes target the latest default branch unless a release-specific policy is documented. This is a community-maintained tool with no guaranteed response or remediation time.

See [security and privacy](docs/security-and-privacy.md) for account checks, credential storage, and revocation. Ordinary setup failures belong in [troubleshooting](docs/troubleshooting.md).
